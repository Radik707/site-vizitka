# Сайт-визитка Олега

## О проекте
Личный сайт-визитка. Цель — представить себя потенциальным клиентам как вайбкодер и специалист по автоматизации бизнесов.

## Страницы
- `index.html` — главная (первое впечатление)
- `about.html` — обо мне
- `services.html` — услуги
- `portfolio.html` — портфолио (примеры работ)
- `contacts.html` — контакты

## Структура
- `styles/main.css` — все стили сайта
- `scripts/main.js` — интерактивность
- `images/` — изображения (фото, иконки, скриншоты работ)

## Стек
Статический сайт: HTML + CSS + JavaScript. Без бэкенда.
