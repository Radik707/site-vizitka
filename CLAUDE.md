# Сайт-визитка Олега

## О проекте
Личный сайт-визитка. Цель — представить Олега потенциальным клиентам как вайбкодера и специалиста по автоматизации бизнесов.

Аудитория: предприниматели и компании, ищущие автоматизацию процессов. Тон — профессиональный, но живой, без канцелярита.

## Стек
Статический сайт: HTML5 + CSS3 + Vanilla JavaScript. Без бэкенда, фреймворков и сборщиков.

## Правила работы

### Общие
- При старте сессии читай primer.md. В конце сессии обновляй его: раздел «Сейчас» перезаписывай полностью, в «Историю» добавляй запись за день. Максимум 50 строк — старое сжимай в сводку.
- Памятки по инфраструктуре, настройкам и долгосрочным фактам лежат в папке памятки/. Обращайся к ним по необходимости, не загружай автоматически.
- Не удалять и не переименовывать файлы без явного согласия пользователя.
- Не добавлять зависимости, npm, сборщики — проект намеренно простой.
- Все изменения — в существующих файлах, новые файлы только по запросу.
- Отвечать на русском языке.

### Код
- Комментарии в коде — только если логика неочевидна, кратко.
- CSS — без классов-утилит в стиле Tailwind, писать семантично.
- JS — без библиотек, только нативный браузерный API.
- Не добавлять обработку ошибок и фолбэки для сценариев, которые не могут случиться на статическом сайте.

### Контент и стиль
- Тексты на русском, живые и конкретные — без шаблонных фраз типа "мы команда профессионалов".
- Фокус на пользе для клиента, а не на перечислении технологий.
- Призывы к действию (CTA) должны быть конкретными: "Написать в Telegram", а не просто "Связаться".
