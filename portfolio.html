01 Автоматизация

Автоматический учёт заявок

n8n Telegram Bot API Google Sheets

Задача

Заявки с сайта терялись: часть падала в почту, часть в CRM, менеджеры дублировали работу и не успевали обрабатывать лиды вовремя.

Решение

02 Сайт

Лендинг для онлайн-школы

HTML / CSS / JS Google Sheets Google Apps Script

Задача

Онлайн-школа работала через Instagram и ручную запись в таблицу. Нужен сайт с автоматическим сбором заявок, подтверждениями и уведомлениями куратору.

03 Telegram-бот

Бот для записи клиентов

Telegram Bot API Google Calendar n8n

Задача

Мастер тратил 1–2 часа в день на переписку: уточнял время, подтверждал записи и напоминал о визитах. Часть клиентов просто не доходила.

Решение

Telegram-бот принимает запись, уточняет удобное время и услугу, добавляет событие в Google Календарь и отправляет клиенту напоминание за час до визита. Мастер просто видит готовое расписание.

04 Автоматизация

Ежедневный отчёт из CRM

Make Google Sheets Telegram Bot API Airtable

Задача

Руководитель тратил 2 часа ежедневно: вручную сводил данные из CRM, таблиц и мессенджеров в один управленческий отчёт.

Решение

Настроил сценарий на Make: данные из CRM и Google Sheets собираются автоматически, формируют ежедневный отчёт и отправляют в Telegram-канал руководителю ровно в 9:00.
