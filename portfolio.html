01 CRM-система

CRM для медтех-бизнеса на EspoCRM

EspoCRM PHP MySQL Docker VPS HTTPS

Задача

02 Веб-приложение

B2B-каталог для торгового представителя

Next.js TypeScript Tailwind Google Sheets Python Cloudinary Vercel

Задача

Владельцы магазинов заказывали по бумажным прайсам — без фото, без актуальных остатков, а заказы приходилось собирать вручную.

Решение

Сделал мобильный B2B-каталог: клиент открывает ссылку, видит товары с фото, ценами и наличием, собирает корзину и отправляет заказ в Telegram. Данные тянутся из Google Sheets, куда Python-скрипт ежедневно заливает прайсы поставщиков из Excel, а фото — в Cloudinary. Задеплоено на Vercel.

03 Автоматизация

Новостной AI-дайджест в Telegram

Python OpenRouter (ИИ) feedparser SQLite Docker cron

Задача

Следить за десятками источников вручную — долго, важное теряется среди шума.

Решение

Собрал агента: каждое утро он тянет новости по RSS, ИИ отбирает значимое и сжимает в короткий дайджест, бот присылает его в Telegram. Работает на сервере в Docker по расписанию — полностью без участия человека.
